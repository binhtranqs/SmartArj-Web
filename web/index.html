Built like a real product, not a class demo.

The project combines domain modeling, protected user workflows, weather data APIs, and payment handling.

Zone and crop management

Users can create growing zones, assign coordinates, manage crop thresholds, and track owner-specific data.

Weather dashboard

Dashboard APIs support temperature, humidity, rainfall, wind, radiation, quick stats, and chart views.

VIP forecasting

VIP users can request forecast data that combines stored history, Open-Meteo fallback data, and an AI prediction service.

Clear layers from request to database.

SmartArj follows a practical MVC-style structure with controllers, services, DAOs, JPA models, JSP views, and shared utilities.

Java Servlet JSP Jakarta EE Hibernate SQL Server Tomcat Chart.js VNPay
Servlets Handle routing, authentication gates, JSON APIs, and page forwarding.
Services Coordinate business rules for dashboard data, zones, crops, alerts, forecasts, and payments.
DAOs Read and write SQL Server data through JPA and Hibernate entities.
Views Render JSP screens for login, dashboard, crop management, zone management, and checkout.
